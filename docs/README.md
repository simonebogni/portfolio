## Introduction

This repository hosts the main code of my personal portfolio website, which is currently hosted on Render.

This website is showing my past and current work experiences, tech skills, education and certifications.

It leverages Laravel 11 as a framework, and PostgreSQL as a RDMS.\
The views for the frontend are built with Blade.

For an overview of the database, check the relevant [documentation](./database/database.md).
